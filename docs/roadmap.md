# Roadmap

- Embedding-based novelty rejection to skip near-duplicate ideas before evaluation.
- Extend the adaptive policy to model choice and parent selection.
- Multiple objectives (for example speed and accuracy) instead of one score.
- Meta-prompt evolution: let the system-prompt hints evolve with the programs.
- An HTML dashboard: score over time, a lineage tree, the per-island niche map.
- Multi-file programs; Slurm and SSH backends beyond the launcher prefix.
